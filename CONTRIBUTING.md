# Jak współtworzyć projekt (Contributing)

Dzięki, że chcesz pomóc w rozwoju **Bezpiecznej Trasy**!

## Zgłaszanie błędów i pomysłów
1. Sprawdź w zakładce **Issues**, czy temat nie był już poruszany.
2. Użyj odpowiedniego szablonu (`Bug report` lub `Feature request`).
3. Opisz dokładnie kroki do odtworzenia błędu.

## Dodawanie zmian (Pull Request)
1. Zrób forka repozytorium i utwórz nowy branch: `git checkout -b feat/moja-zmiana`.
2. Wprowadź zmiany i dopisz testy w katalogu `tests/`.
3. Upewnij się, że testy i linter przechodzą:
   ```bash
   bun test
   bun run lint
   ```
4. Otwórz Pull Request i wypełnij szablon PR.
